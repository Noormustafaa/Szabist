Step2: Creating a Schema Inside the Database Szabist3.

	Click on Szabist3 and Right Click on Schema Then Click on Create and then write name of schema 
		academic_schema1   And then click on Save .

Step3: Create a Table in Szabist3 Database .
	Right click on Szabist3 Database and and click on Query tool. 
        And Create The Table in academic_schema1

step10: Assign Limited Privileges to the user : Now we just want that szabist_viewer1  just read the data (read Only / select) only on Academic schema and its student table . this user will not able to insert or delete the record .

So Write on Query --

GRANT USAGE ON SCHEMA  academic_schema1 TO szabist_viewer1;

--in this command we just Grant to this particular user ! 


Step10-- this Query will just Give access to read data !



GRANT SELECT ON ALL TABLES IN SCHEMA academic_schema1 TO szabist_viewer1;
