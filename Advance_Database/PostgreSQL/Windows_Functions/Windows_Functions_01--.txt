--Applying Windows Functions 
--Window Function (ROW_NUMBER)
Select name, Department , Salary , 
	Row_Number() Over (Partition BY department order by salary DESC) as row_num 
	from employees;




1--PARTITION BY department: This divides the data into separate groups (partitions)
 based on departments (such as IT, HR, and Sales). This means the data for each department is treated independently.

2--ORDER BY salary DESC: This sorts the employees' salaries within each department in descending order—from highest to lowest.


3--ROW_NUMBER(): This function assigns a sequential number (1, 2, 3...) to employees within each department based on their salary ranking.

4--The employee with the highest salary in that department gets row_num = 1, the next highest gets 2, and so on.

5--Whenever a new department begins (for example, moving from IT to HR), the numbering resets and starts over from 1
