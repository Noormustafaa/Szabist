type5--cross Join 

A Cross Join is a SQL operation that combines every single row from the first table with every single row from the second table.

It generates a Cartesian product, meaning it pairs each record in Table A with every individual record in Table B.

It does not require any matching condition or ON clause, which often results in a massive output containing rows equal to the total rows of Table A multiplied by Table B.

--command 



SELECT name, contact, dept 
FROM personal 
CROSS JOIN professional;
