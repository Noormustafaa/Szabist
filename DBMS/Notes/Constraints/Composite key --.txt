Composite key --

A composite key is a primary key made up of two or more columns combined to uniquely identify each row in a table.

Individually, none of these columns are unique on their own, but together their combination is completely unique.

CREATE TABLE Enrollments (
    StudentID INT,
    CourseID VARCHAR(10),
    EnrollmentDate DATE,
    PRIMARY KEY (StudentID, CourseID) -- Composite Key
);
